# Portfolio Data Analyst

Portfolio personnel, moderne et responsive, construit en HTML, CSS et JavaScript sans framework.

## Aperçu

Ce projet présente un portfolio de Data Analyst avec une identité visuelle minimaliste en bleu nuit, blanc et bleu clair. Il comprend les sections suivantes :

- Accueil
- À propos
- Compétences
- Projets
- Formation
- Contact

## Structure du projet

- `index.html` : structure HTML du site
- `style.css` : styles et responsive design
- `script.js` : sélecteur de langue français/anglais et mémorisation du choix

## Langues

Le sélecteur dans l’en-tête permet de passer du français à l’anglais. La langue choisie est mémorisée dans le navigateur.

## Déploiement sur GitHub Pages

1. Enregistrez ce dépôt sur GitHub.
2. Ouvrez les paramètres du dépôt.
3. Allez dans la section "Pages".
4. Sélectionnez la branche principale (`main` ou `master`).
5. Gardez le dossier racine comme source (` / `).
6. Enregistrez pour publier le site.

GitHub Pages servira automatiquement le fichier `index.html` dans la racine du dépôt.

## Personnalisation

- Remplacez le texte de présentation par votre propre contenu.
- Mettez à jour les liens vers vos projets GitHub, LinkedIn et votre e-mail.
- Ajoutez vos propres captures d’écran ou projets dans la section des projets.

## Lancement local

Vous pouvez prévisualiser le site localement avec un simple serveur statique :

```bash
python -m http.server 8000
```

Ensuite, ouvrez :

```text
http://localhost:8000
```

## Notes

- Le design est pensé pour les écrans mobiles et les grands écrans.
- Les liens de navigation utilisent des ancres internes pour une expérience fluide.
- Les informations affichées sont volontairement générales et ne font référence à aucune expérience ou certification fictive.
